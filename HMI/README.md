# HMI Design – Industrial OEE System

This folder contains the Mitsubishi GOT HMI design developed using GT Designer3.

## HMI Screens

1. Home Screen – Machine status and mode selection.
2. Production Monitor – Production data and OEE parameters.
3. Settings / Modes – Machine controls and configuration.
4. Alarm / Fault – Fault monitoring and alarm management.

## Software
- GT Designer3
- GT Simulator3

## Project File
`OEE_HMI_Design.gtx`

The HMI communicates with the Mitsubishi FX5U PLC through configured PLC devices.
