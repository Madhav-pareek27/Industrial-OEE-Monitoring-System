# Project Documentation

This folder contains the technical documentation and device allocation details of the Industrial OEE Monitoring and Control System.

## Files Included

### 1. Final Project Report – PDF
A detailed report covering:
- Introduction and project objectives
- PLC and HMI architecture
- OEE theory and calculations
- PLC device allocation
- Ladder program explanation
- HMI screen design
- PLC-HMI integration
- Testing, observations and future scope

### 2. PLC-HMI Device Allocation – Excel
Contains the PLC device addresses, descriptions, functions and corresponding HMI object mapping.

## Purpose

These documents provide technical reference material for understanding, configuring and maintaining the OEE monitoring project.
